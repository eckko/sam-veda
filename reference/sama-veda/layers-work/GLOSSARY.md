# Fixed renderings (Sāmaveda). Extended by reviewers, not drafters.
- indra = Indra; agni = Agni; pūṣan = Pūṣan; deva = god; maghavan = O bountiful one (Maghavan); vajrin = O wielder of the thunderbolt; śakra = the mighty one (Śakra); vṛtrahan = O slayer of Vṛtra
- ṛṣi = sage; soma = Soma; ṛc = verse; sāman = chant (sāman)
- Stobha syllables (hāu, hoyi, ā3, o3 …) and pluta marks (३, ऽ३) are kept in `src`, glossed "chant syllable (stobha)", and are not translated.
- Hindi: इन्द्र, अग्नि, सोम, पूषन्, देवगण; no Latin letters.
- adrivas = O wielder of the stone (हे पत्थर के धारी); śaviṣṭha = O most mighty (हे सबसे बलवान); maṃhiṣṭha = O most bountiful (हे सबसे उदार); vajrin (Hindi) = वज्रधारी; vaso = O good one (हे वसु); cikitvas = O wise one (हे ज्ञानी)
- svar = light of heaven (सूर्य का प्रकाश); evā hi = Thus indeed (इस प्रकार ही)
- refrain "sa naḥ svarṣad ati dviṣaḥ" = "May he carry us beyond hostilities" (वह हमें शत्रुताओं के पार ले जाए); svarṣat root uncertain
- vidā in "gātuṃ vid" = find (पाओ), not know
- vajrī = the wielder of the thunderbolt (वज्रधारी); puruṣa = the Puruṣa (पुरुष); dyāvāpṛthivī = Heaven and Earth (द्यावा-पृथिवी); apāṃ napāt = the Son of the Waters (अपां नपात्); jātavedas = Jātavedas (जातवेदा); vaiśvānara = Vaiśvānara (वैश्वानर); prajāpati = Prajāpati (प्रजापति); varuṇa = Varuṇa (वरुण); mitra = Mitra (मित्र); aditi = Aditi (अदिति); sūrya = Sūrya / the sun (सूर्य); rodasī = the two worlds (दोनों लोक); aṃhas = distress (संकट); yaśas = glory (यश); varcas = lustre (तेज); vāja = prize/strength (वाज)
- A pluta figure 3 inside a token is its own word {"w":"3"} glossed "pluta (prolongation) mark; chant syllable (stobha)" and is never translated.
- hotṛ = Hotṛ priest (होता); adhvara = rite (यज्ञ); yajña = sacrifice (यज्ञ); gir = song (स्तुति); stoma = hymn (स्तोत्र); barhis = sacred grass (कुशासन); dāśvas = giver (दाता); kṛṣṭi = peoples (लोग); viśpati = lord of the clans (प्रजाओं के स्वामी); pāvaka = O purifier (हे पावक); ṛta = truth (ऋत); indu = drop (बूँद), no "Soma" added
- Vocatives of -tṛ stems end in -tar (jaritar, trātar). Compounds are not split at suffixes (-mat, -tama). Hindi uses no parentheses.
- vipra = the inspired one (प्रेरित मेधावी), distinct from ṛṣi = sage; brahmā (priest) = priest (brahman), Hindi ब्रह्म-पुरोहित, not the god; maṃhiṣṭha = most bountiful (सबसे उदार); brahmaṇaspati = lord of the sacred word (ब्रह्मणस्पति); savitṛ = Savitṛ (सविता); sridh = failing ones (विफल होने वाले); tuvi- = strong/mighty (सुदृढ़); vṛṣā, vṛṣabha = mighty one / bull, never "steer"; aram = fitting (उचित)
- uṣas = Dawn (उषा); aśvin = the Aśvins (अश्विन्); marut = the Maruts (मरुत्); sarasvatī = Sarasvatī (सरस्वती); tvaṣṭṛ = Tvaṣṭṛ (त्वष्टा); Dadhīci, Nahuṣa, Kaṇva = names kept as given; hari = bay horse (Hindi: भूरा/लाल-भूरा घोड़ा, not "green"); śatakratu = hundred-powered (सौ शक्तियों वाला); div/dyu = heaven (आकाश); avabhṛtha = the concluding bath (avabhṛtha); navatīr nava = nine and ninety (नौ और नब्बे); sakhāyaḥ (voc.) = O friends (हे मित्रो); maghonām = of the bountiful ones; hotrā = offerings; vaṣṭu = desires
- girvaṇas = O lover of praise (हे स्तुतिप्रिय); śūra = hero (शूर); stotṛ = singer (स्तोता); aryaman = Aryaman (अर्यमा); viṣṇu = Viṣṇu (विष्णु); harivān = owner of bay horses (भूरे घोड़ों वाला); rādhas = bounty (Hindi: उदारता, one word throughout); iṣ/iṣā = refreshment (पोषण); Namuci, Vasiṣṭha = names, no added role
- Unreadable or obscure text: translate literally what is clear, mark the rest "[unclear]" in English and "(अस्पष्ट)" is NOT allowed in Hindi; put the doubt in notes and set confidence low. Hindi has no brackets; English parentheses only for the Sanskrit term, as in "(brahman)".
- kavi = seer (कवि), distinct from ṛṣi = sage; vṛtrahantama = best slayer of Vṛtra; vṛtra = Vṛtra (one choice throughout); brahman (priest) = Brahman priest (ब्रह्मन्), not ब्रह्मा; vivaṣṭu = let him desire; ānava = Ānava (आनव); Draviṇodas and similar Agni epithets stay names; vāja is always वाज in Hindi.
- dyumna = splendour (द्युम्न), distinct from yaśas = glory and varcas = lustre (तेज); bhūṣ = honour (सत्कार); śakra (voc.) = O mighty one (हे शक्र); vajrin (voc.) Hindi = हे वज्रधारी; maghavat = bountiful one, not "patron"/यजमान; varūtha = shelter (आश्रय); savana = pressing (सवन); andhas = juice; āpya = kinship; medhyātithe = O Medhyātithi (voc.); cana printed as ca + na: gloss the halves, translate once.
- Do not split at -vat, -vant, -mant, -tva either (amṛtatva stays whole). kalaśa = vessel (कलश); kośa = vat (कोश); vāra = strainer (छन्नी); pavitra = filter (छन्ना); hari as epithet of Soma = tawny (भूरा/लाल-भूरा); kratu = power (सामर्थ्य); iṣaspati = lord of refreshment (पोषण के स्वामी); iḍā = refreshment (पोषण); amīvā = disease (रोग); a-rādhas = ungenerous (उदारताहीन); dīdhiti = insight (अंतर्दृष्टि); ṛta = truth, never "Order"; devas (plural, Hindi) = देवगण; "Friends" in address = "O friends".
- svānā(ḥ) may stand for suvānā(ḥ) "being pressed" (RV parallel): note only, do not apply.
